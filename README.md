# Disk Analyzer

Приложение для анализа использования дискового пространства — упрощённый аналог WizTree.  
Написано на C# / .NET 10, WPF. Учебный проект, демонстрирующий чистую архитектуру, принципы ООП и паттерн MVVM.

## Скриншот

> Запустите приложение и выберите диск для сканирования.

## Возможности

- **Сканирование диска или папки** — асинхронно, UI не замерзает
- **Отображение дерева папок** — TreeView + DataGrid с синхронизацией
- **Навигация по хлебным крошкам** — кликабельные сегменты пути
- **Сортировка** — по размеру, имени, количеству файлов
- **Статистика по расширениям** — топ расширений с размером и процентом
- **Топ-50 самых больших файлов**
- **Экспорт** в CSV и текстовый файл с деревом
- **Тёмная и светлая тема** — переключается в настройках
- **Console-режим** — сканирование и отчёты из командной строки
- **Отмена сканирования** — через CancellationToken, без зависания

## Быстрый старт

### Требования

- Windows 10/11
- [.NET 10 SDK](https://dotnet.microsoft.com/download)

### Сборка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/vasko/disk-analyzer.git
cd disk-analyzer

# Сборка всего решения
dotnet build

# Запуск WPF-приложения
dotnet run --project DiskAnalyzer.WPF

# Запуск консольного приложения
dotnet run --project DiskAnalyzer.Console -- C:\Users --top 10
```

### Использование консоли

```
diskanalyzer <путь>                    Сканировать и показать топ папок
diskanalyzer <путь> --top N            Показать топ N папок
diskanalyzer <путь> --sort name        Сортировка по имени
diskanalyzer <путь> --depth 2          Ограничить глубину сканирования
diskanalyzer <путь> --extensions       Показать статистику по расширениям
diskanalyzer <путь> --export csv       Экспорт в CSV
diskanalyzer <путь> --output rep.csv   Указать имя файла
diskanalyzer --drives                  Список доступных дисков
```

## Горячие клавиши (WPF)

| Клавиша     | Действие                        |
|------------|----------------------------------|
| `F5`       | Начать сканирование / Обновить   |
| `Escape`   | Отменить сканирование            |
| `Backspace`| Перейти в родительскую папку     |
| `Enter`    | Войти в выбранную папку          |
| `F2`       | Выбрать папку через диалог       |
| `F1`       | Показать справку                 |
| `Ctrl+E`   | Экспорт в CSV                    |
| `Ctrl+T`   | Экспорт в текстовый файл         |
| `Ctrl+,`   | Открыть настройки                |

## Настройки

Файл настроек: `%AppData%\DiskAnalyzer\settings.json`

| Параметр                | По умолчанию    | Описание                          |
|------------------------|-----------------|-----------------------------------|
| `SkipSystemFolders`    | `true`          | Пропускать системные папки        |
| `SkipHiddenFiles`      | `false`         | Пропускать скрытые файлы          |
| `MaxDepthLimit`        | `0` (без лимита)| Максимальная глубина сканирования |
| `Theme`                | `"Dark"`        | Тема: `"Dark"` или `"Light"`      |
| `ShowFileExtensionStats`| `true`         | Показывать статистику расширений  |
